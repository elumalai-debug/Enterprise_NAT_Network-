# 🌐 Enterprise NAT Network Simulation using Cisco Packet Tracer

## 📖 Project Overview

This project demonstrates the implementation of an enterprise network using Cisco Packet Tracer. It simulates communication between multiple branch offices and public servers through an ISP network using various Network Address Translation (NAT) techniques.

The project includes Static NAT, Dynamic NAT, PAT (NAT Overload), RIP routing, DNS services, and HTTP/HTTPS web servers to provide realistic enterprise networking scenarios.

---

## 🚀 Features

- Static NAT
- Dynamic NAT
- Dynamic NAT Overload (PAT)
- RIP Routing Protocol
- DNS Server Configuration
- HTTP & HTTPS Web Servers
- Multiple Branch Networks
- ISP Network Simulation
- Private and Public IP Addressing
- End-to-End Connectivity Testing
- Web Browser Access using Domain Names
- ICMP (Ping) Connectivity Verification
